# Security and privacy checklist

- [x] Demo UI labels all records as sample data and does not connect to production systems.
- [x] No credentials or real agency/personnel data are present in fixtures.
- [x] Upload and analysis flows are simulated; no uploaded file is processed.
- [x] Pilot form has required fields, email validation, consent, and a recoverable success state.
- [ ] Select and configure a server-side managed form destination with spam protection and rate limiting.
- [ ] Add a production CSP and deployment-specific secure headers before public launch.
- [ ] Complete dependency audit and manual keyboard/accessibility review before calling a demo launch complete.
- [ ] Define retention/deletion expectations before collecting pilot or interview material.

Knowledge Succession Room must keep personal transition information separate from operational knowledge and must not collect protected HR or medical details. Policy Impact Mapper assists implementation planning and does not provide legal advice or authoritative interpretation.
