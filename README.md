# Top Five Venture Lab

A dependency-free, Vercel-ready set of interactive MVP mockups for:

1. Legacy Parity Room
2. Agent-Safe Data Gateway
3. Public-Data Evidence Room
4. Knowledge Succession Room
5. Policy Impact Mapper

## Local preview

```bash
python3 -m http.server 3000
```

Open `http://localhost:3000`.

## Vercel

Import the repository into Vercel as an **Other / Static** project. No build command, output directory, or environment variables are required.

The portfolio landing page links to five interactive product workspaces under `/products/?slug=<product-slug>`.
